# HelloCSharp — Simple C# Console Calculator

A simple C# console application created for **COMP 019 – Applications Development and Emerging Technologies (Activity 2)**.

## What it does
- Greets the user.
- Shows a menu (Add, Subtract, Multiply, Divide, Exit).
- Reads two numbers and prints the result.
- Validates input and guards against division by zero.

## Concepts demonstrated
- `Main` method and a custom `MyMethod`-style helper methods
- `using System;` namespace import
- Data types: `string`, `double`, `bool`
- Control flow: `while` loop, `switch`, `if`
- Console input/output

## How to run
```bash
dotnet run
```
